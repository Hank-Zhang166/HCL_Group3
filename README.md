# 人机交互第三小组

这是第三小组的内部代码仓库，用来测试 Git 的**共享修改**功能。

> 关于仓库名：GitHub 的仓库名只允许英文字母、数字以及 `-` `_` `.`，
> 中文会被自动替换成 `-`。所以中文名适合写在仓库简介（About → Description）
> 和本文件的标题里，仓库地址建议用一个英文名，例如 `HCI-Group-3`。

## 运行测试代码

双击 `run.bat` 即可运行（需要已安装 Python 3），也可以手动执行：

```
python main.py
```

运行后会弹出一个对话框，显示：**欢迎来到第三小组的奇思妙想之旅！**

## 如何测试共享修改

1. 组员 A 打开 `main.py`，把 `WELCOME_TEXT` 改成自己想说的话（或新建一个 `<姓名>.txt`）。
2. 组员 A 提交并推送：

   ```
   git pull
   git add .
   git commit -m "修改了欢迎语"
   git push
   ```

3. 组员 B 执行 `git pull`，再运行 `python main.py`，就能看到 A 的改动。
